# Introduction

1. Player lands in sewers
- encourage player to continue moving right by entering already moving to the right
- teach player hook range by placing nearest ceiling just outside range (but only one roll required to reach it)
2. introduce basic swing mechanics
- flat ceiling allows experimentation with minimal free variables
- recovery zone beneath ceiling so mistakes while experimenting aren't punished
3. SKILL CHECK #1: mid-swing hook
- two pipes spaced barely greater than hook range requires player to deploy hook while swinging
4. introduce impermeable walls
- player must use anchor geometry to progress upwards
4. introduce background anchor geometry
- encourage player to move up by entering vertical chamber
- encourage player to attach to anchor by making only two obvious attachment points visible
- player must attach to first anchor to reach second anchor
- player must swing through first anchor to reach third anchor
5. SKILL CHECK #2: >90 degree swing
- anchor point placed above second anchor requires player to deploy hook while above their anchor point
