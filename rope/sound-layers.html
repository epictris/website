Saving & applying

Edits are kept in this browser. Save draft writes the editable project to disk. Apply renders a new game asset and replaces this event’s selected variation. Other variations and event-volume settings stay intact.

Editing & source details

Each track refers to an original recording. Gain, pitch, filters, fades and repeated grains remain editable. Move layer shifts all clips on that track. Mute and solo affect previews and exports.

Effects tails end at the project length; extend Length to let them ring. Monitor changes listening volume only. Exported mixes are not normalized automatically. Use Set −3 dB peak to adjust headroom.

The game’s velocity, strength, variation and material rules still apply after assignment. Select each material event separately to edit its overrides.
